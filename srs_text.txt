Software Requirements Specification (SRS)
Project Title
Bengali Hotel Restaurant Ordering System
Version
1.0
Client
Bengali Hotel, Saidulajab, Saket, New Delhi - 110030
1. Introduction
1.1 Purpose
The purpose of this system is to provide customers with an online ordering platform for Bengali Hotel Restaurant where customers can browse menu items, add products to a cart, and place orders without online payment.
The system will automatically notify restaurant staff and management when an order is placed.
1.2 Scope
The website shall:
Allow customer login using Name and Mobile Number.
Display complete restaurant menu.
Allow item quantity selection.
Allow Premium Packaging selection.
Generate unique Order IDs.
Store customer and order history.
Send notifications via WhatsApp and Email.
Provide an owner dashboard with revenue analytics.
